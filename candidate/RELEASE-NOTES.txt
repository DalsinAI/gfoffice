GFOffice 2.0.25 RC93 for AmigaOS 3
==================================

Release candidate: gfoffice-2.0.25-rc93 (pre-release)
Previous release: RC92 (2f27338e, 18 Nov 2026).
What built it (source commit, stove, compiler, pinned parts) is in
BUILD-INFO.txt, written by the build itself.

What is new since RC92
----------------------
* Built with the open9 stove (os32-gcc16-open9), in LumaVAULT's kitchen.
  The programs' sources are RC92's: no program has a new version number.
* The package is made by the repository's own scripts/package.sh, from
  build-rc.sh, with the version in candidate/VERSION.
* Spelling works from the package as it comes: the word list is in the
  Dictionaries drawer beside the programs, and the install below now names
  owfspell.library. RC92 had no word list and its install did not name the
  library, so spelling worked only where an earlier install had left them.
* The library tests come with the files they read (library/tests).

INSTALL: FOUR LIBRARIES GO IN LIBS:
-----------------------------------
The programs open libraries, and the package carries them in the library
drawer. From a Shell in the GFOffice drawer:

    Execute Install-Libraries

which does these four copies:

    Copy library/gfopenlayout.library LIBS:
    Copy library/sqlite.library LIBS:
    Copy library/gfopendraw.library LIBS:
    Copy library/owfspell.library LIBS:

then restart the Amiga, so that an older gfopenlayout.library already in
memory is not the one the programs get.

  gfopenlayout.library 25  GFOpenWrite, GFOpenPresentation,
                           GFOpenPressmaster, GFOpenBase (report preview),
                           OWConvert (a presentation to PDF) need 24;
                           GFOpenDiag and GFOpenProject need 25;
                           GFOpenDrawOL needs 10.
  sqlite.library 1         GFOpenBase.
  gfopendraw.library 1     GFOpenDraw and GFOpenDrawOL.
  owfspell.library 1.1     Spelling in every program that checks it.

A program that does not find its library says which one it needs and ends
(a requester from Workbench, a line in a Shell). GFOpenCalc needs none of
the first three. Without owfspell.library a program runs and says so when
spelling is asked for. The owf libraries in the same drawer are for programs built on
them and for developers; the programs here have libowf linked in.

Lab
---
Checked on 23 November 2026 in the lab t2-lister-putty-20261114 (Kickstart
47.2, Workbench 47.100), with the four libraries copied to LIBS: from the
package and the programs run from the package's drawer:

* The libraries load: gfopenlayout.library 25.0, sqlite.library 1.0,
  gfopendraw.library 1.0, owfspell.library 1.1.
* Every program starts and ends cleanly. GFOpenWrite opens
  OpenWrite-Tour.docx, GFOpenCalc features-openpyxl.xlsx (8 sheets),
  GFOpenPresentation pptx-talk.pptx (5 slides); GFOpenBase makes a new
  database and opens it again; GFOpenDiag, GFOpenProject, GFOpenPressmaster,
  GFOpenDraw and GFOpenDrawOL open their windows.
* OWConvert: pptx to PDF, docx to PDF, xlsx to ods.
* Spelling (through ARexx SPELL): GFOpenCalc, GFOpenDiag, GFOpenProject and
  GFOpenPresentation find misspelt words typed in and suggest for them;
  GFOpenBase checks and suggests.
* GFOpenCalc External Data: a table from a saved web page comes in and
  refreshes. Reading a database is not in this build (it says so).
* GFOpenProject: the Gantt, Resource Usage, Task Usage, Network and
  Resource Graph views each export to PDF.
* GFOpenPresentation table tools: merge, split, row height and design on a
  table in pptx-talk.pptx, undone and saved as .pptx.
* The library tests, run from library/tests with the files they read:
  OWFLibTest 133 passed, 0 failed; OWFLibsTest 380 passed, 0 failed;
  OWFSpellTest 0 failed.

Not run in the lab: GFOpenPressmaster's Facing Pages and tracked format
changes in an ODT file (both are covered by the unit tests, and neither has
changed since RC92).

Known
-----
* GFOpenBase leaves an empty NAME.oadb.lck beside the database after it
  quits. It is not held and the database opens again.
* gfopenlayout.library 25 replaces an older file in LIBS:. It has every
  call of the older versions.

The programs with their icons; library/ with gfopenlayout.library,
sqlite.library, gfopendraw.library and the owf libraries (owf, owfwrite,
owfcalc, owfpresent, owfpub, owfdiag, owfspell) and their tests; sdk/;
Images/Toolbar; Rexx; Dictionaries; Documentation; samples; BUILD-INFO.txt;
